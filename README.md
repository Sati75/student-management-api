# Student Management API

A RESTful API built using Spring Boot and H2 Database.

## Technologies Used

- Java 21
- Spring Boot 3
- Spring Data JPA
- H2 Database
- Swagger OpenAPI
- Maven

## Features

- Create Student
- Get All Students
- Get Student By ID
- Update Student
- Delete Student
- Validation
- Exception Handling

## Run the Application

```bash
mvn spring-boot:run
```

## Swagger UI

http://localhost:8081/swagger-ui/index.html

## H2 Console

http://localhost:8081/h2-console
